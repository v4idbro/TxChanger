## Requirements

Python 3

## Installation

```
git clone https://github.com/v4idbro/TxChanger
cd TxChanger
```

## Usage

```
python3 TxChanger.py
```

Select option 1, enter the interval in seconds when asked "How soon should it change?", then enter the duration in seconds when asked "For how long?" or leave it blank to run forever.

Stop the program with Ctrl+C.

## Proxies

Edit `proxies.txt` and add one proxy per line in the format `ip:port`.
